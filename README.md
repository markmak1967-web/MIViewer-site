# MIViewer — test site

Published build of the MISB motion imagery viewer: **https://markmak1967-web.github.io/MIViewer-site/**

Single self-contained HTML file. Drop a MISB MPEG-TS, MP4, KLV or sidecar file onto the page. Files are processed locally in your browser and nothing is uploaded.
Source is maintained in a private repository; this repo only holds the built `index.html`.
